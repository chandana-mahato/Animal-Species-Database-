## Project Overview
A comprehensive database application built with Python and SQLite to manage and explore information about various animal species.

## Features
* Add new species with detailed information
* Search species by name, description, or classification
* View all species or specific species details
* Update existing species information
* Delete species from the database

## Technologies Used
* Python
* SQLite

## Installation
1. Clone the repository: `git clone https://github.com/your-username/animal-species-database.git`
2. Navigate to the project directory: `cd animal-species-database`
3. Run the application: `python animal_species_database.py`

## Usage
1. Run the application and follow the menu-driven interface.
2. Add, search, view, update, or delete species as needed.
